{"source":"gemini","id":"resp-123","ts":"2026-11-09T14:00:00Z","cwd":"/home/voce/ampm/saff/ms-sales","model":"gemini-3-pro","input":1200,"output":300,"cacheRead":0}

        O ai-memory guarda o que os agentes aprendem em cada projeto e entrega um resumo no começo de cada sessão. Funciona sem chave de API.

          Dados:

          Instalar faz, nesta ordem:

          1. baixa a imagem do ai-memory no Docker (~200 MB);
          2. cria a pasta dos dados, com um token para ninguém mais ler a memória;
          3. sobe o servidor, só para esta máquina (127.0.0.1:49374), religando sozinho com o computador;
          4. instala o comando ai-memory (conferido pelo checksum) e liga hooks e MCP no Claude Code.

          Os hooks valem para todas as sessões do Claude nesta máquina, não só as do escritório.
